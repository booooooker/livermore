利弗莫尔交易策略实战手册（基于女娲 SKILL 框架）
本项目是基于女娲 SKILL心智蒸馏而成的利弗莫尔交易助手，完整复刻并落地杰西・利弗莫尔经典交易哲学与实战体系。
它不仅是一套量化策略模型，更是一位可交流、可咨询的交易伙伴，你在实盘、复盘、仓位管理、心态控制等方面遇到的各类交易问题，均可向其咨询获取思路与方案。
一、项目简介
核心来源：女娲 SKILL 心智蒸馏
交易内核：杰西・利弗莫尔经典交易体系
趋势跟踪与关键点交易
金字塔仓位管理
止损与止盈纪律
市场情绪与时机判断
定位：可对话、可咨询、可落地的交易辅助系统，面向趋势交易者、短线交易者、量化爱好者使用。
二、适用人群
趋势交易者，希望建立稳定、规则化的交易系统
学习利弗莫尔交易思想，但难以落地执行的投资者
需要实时咨询、思路梳理、决策辅助的交易员
量化入门者，希望用简单方式使用成熟交易逻辑
三、功能与使用场景
1. 交易问题咨询（核心功能）
你可以直接向模型提问，包括但不限于：
当前趋势如何判断？
这个品种是否符合关键点入场条件？
现在该加仓、减仓还是持有？
止损怎么设置更合理？
连续亏损如何调整心态与策略？
如何避免追涨杀跌、过早止盈？
2. 交易逻辑落地
基于利弗莫尔核心规则，自动 / 半自动给出：
入场时机参考
仓位大小建议
止损位、止盈位规划
趋势强弱判断
3. 复盘与成长
支持对历史交易记录进行复盘分析：
指出违反规则的操作
优化入场出场逻辑
建立个人交易纪律清单
四、使用方式
启动模型
按项目运行说明启动女娲 SKILL 蒸馏后的利弗莫尔助手。
提问格式（推荐）
直接以自然语言描述你的问题，例如：
“现在这个走势是不是关键点突破？”
“我被套了，按照利弗莫尔的方法该怎么处理？”
“帮我制定一套日内趋势交易的纪律。”
交互原则
尽量说明：品种、周期、持仓情况、风险承受能力
模型给出的为思路与策略参考，不构成直接投资建议
五、重要说明
本模型基于历史交易思想蒸馏而成，不保证未来收益。
所有咨询结果为交易逻辑参考，实盘需自行决策并承担风险。
严格遵守仓位管理与止损纪律，是利弗莫尔体系的核心，切勿重仓、扛单。
市场永远存在不确定性，模型仅辅助判断，不替代独立思考。
